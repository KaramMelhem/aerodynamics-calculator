# Aerodynamics Calculator ✈️

A simple Python application designed to compute essential aerodynamic values for aircraft design and analysis, such as **Lift Force ($L$)**.

## Formula Used
The Lift equation is defined as:
$$L = \frac{1}{2} \cdot \rho \cdot v^2 \cdot S \cdot C_L$$

Where:
- $L$ = Lift Force (Newtons)
- $\rho$ = Air Density ($kg/m^3$)
- $v$ = Airspeed ($m/s$)
- $S$ = Wing Area ($m^2$)
- $C_L$ = Lift Coefficient
